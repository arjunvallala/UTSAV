# Decisions

- **Local first:** no account or personal identifier is required; the sample wedding opens immediately.
- **Deterministic money and readiness:** AI recommends, pure domain functions calculate.
- **Proposal before mutation:** rescheduling previews every dependent date and waits for explicit approval; simulations never write to the event.
- **Honest vendor data:** the wedding starts with empty category shortlist slots, not fabricated supplier identities. Unprovided quotes display as not received; the app never invents reviews or contact claims.
- **Optional AI:** no credential means a useful deterministic fallback. Gemini model is configurable with `GEMINI_MODEL` and defaults to `gemini-3.8-flash`, listed as the current stable Flash model in Google's model documentation (checked 2026-10-31).
- **In-browser persistence:** schema version is embedded in every event, enabling future migrations and data deletion.
