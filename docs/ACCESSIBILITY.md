# Accessibility

The interface uses semantic navigation, headings, buttons, labels, visible keyboard focus, status announcements, accessible task controls, dialog names, text descriptions for readiness, and reduced-motion handling. Layout rules support narrow mobile widths and browser zoom through fluid sizing.

Automated axe-core auditing and manual screen-reader/keyboard review have not yet been run. Do not represent WCAG 2.2 AA conformance until those checks are completed. Verify the dashboard, dialogs and all planning views with keyboard only, a screen reader, 200% zoom and a 320px viewport.
